mpi_lab script generator + manager (web)

Quick Guide

  • MPI: Select one or more MPI implementations to include.
  • Topology: Choose node/rank layout. Msg Size labels update dynamically based on your selection.
  • Msg Size: Three grid sizes sorted small → medium → large. Labels show the X/Y/Z face message sizes for the selected topology.
  • Compute mode: Scripts are automatically generated for both compute modes (midcomm and no_midcomm) — no manual selection needed.
  • Cluster: Choose one or both target partitions for script generation.
